================================================================================
                    P4_RAG项目案例 —— 项目总结
================================================================================

一、项目概述
--------------------------------------------------------------------------------
本项目是一个基于 RAG（检索增强生成，Retrieval-Augmented Generation）技术
搭建的「家里蹲大学」AI 智能问答系统。

它把学校相关的私有文档（招生政策、专业介绍、历年分数线、校园制度、服务指南、
尺码推荐、竞赛获奖等）导入向量数据库，用户提问时系统先从知识库检索出最相关
的文档片段，再交给大模型结合这些资料回答问题，从而缓解大模型的"幻觉"问题，
让回答有据可依。同时支持多轮对话记忆，同一个用户连续提问时可以理解上下文。

简单概括：读取私有知识库 + 结合历史对话，让大模型依据自有文档回答用户问题。

二、技术栈
--------------------------------------------------------------------------------
- 开发语言        ：Python
- LLM 大模型      ：阿里云 DashScope 通义千问（qwen3-max，对话生成）
- 向量嵌入模型    ：DashScope text-embedding-v4（文本向量化）
- 向量数据库      ：Chroma（本地持久化）
- 应用框架        ：LangChain（LangChain Core / LangChain Community）
- 文本分片        ：RecursiveCharacterTextSplitter（递归字符分割器）
- Web 界面        ：Streamlit
- 对话记忆        ：本地 JSON 文件持久化（自定义实现）

三、核心功能
--------------------------------------------------------------------------------
1. 知识库离线入库：读取 txt 文档 → MD5 去重 → 文本分片 → 向量化 → 写入 Chroma
2. 向量相似度检索：根据用户问题检索 Top-K 最相关的文档片段
3. 检索增强问答：检索结果 + 对话历史 + 用户问题 → 拼装 Prompt → 大模型生成回答
4. 多轮对话记忆：按 session_id 将历史对话持久化为本地 JSON 文件
5. Web 交互界面：Streamlit 聊天界面，支持流式输出回答
6. 知识库在线更新：通过 Streamlit 页面直接上传 txt 文件入库

├── app_qa.py               项目主程序（启动对话 Web 界面）
├── app_file_uploader.py    知识库更新主程序（文件上传 Web 界面）
├── data/                   知识库源文档（txt 文件）
│   ├── 01_招生政策.txt
│   ├── 02_院校专业介绍.txt
│   ├── 03_历年录取分数线.txt
│   ├── 05_校园规章制度.txt
│   ├── 06_校园服务指南.txt
│   ├── 尺码推荐.txt
│   └── 竞赛获奖.txt
├── chroma_db/              向量数据库持久化目录

各文件详细说明：
1. config_data.py —— 配置文件，集中管理：
   - collection_name 向量集合名（"rag"）
   - persist_directory 向量库路径（chroma_db）
   - chunk_size=1000 / chunk_overlap=100（分片大小与重叠）
   - separators 分割符号列表
   - similarity_threshold=2（检索返回 Top-2）
   - embedding_model_name / chat_model_name（模型名）
   - md5_path 去重记录文件路径

2. knowledge_base.py —— 知识库更新服务（离线）：
   - 计算字符串 MD5，用于内容去重
   - check_md5 / save_md5：读取、写入 MD5 记录
   - KnowledgeBaseService 类：
     · 初始化 Chroma 向量库与文本分割器
     · upload_by_str()：文本入库主逻辑（MD5 去重 → 分片 → 向量化入库 → 保存 MD5）

3. vector_stores.py —— 向量存储服务（在线）：
   - VectorStoreService 类封装 Chroma 初始化
   - get_retriever()：返回检索器，k 从配置读取

4. rag.py —— RAG 核心服务（在线），核心链路：
   - 提示词模板：系统指令 + 参考资料(context) + 对话历史(history) + 用户提问(input)
   - format_document：把检索到的文档列表拼接成文本
   - format_for_retriever：提取用户 query 供检索
   - format_for_prompt_template：重整数据结构适配 prompt 模板
   - RunnableWithMessageHistory：包装成支持多轮对话记忆的链

5. file_history_store.py —— 会话记忆存储：
   - FileChatMessageHistory 类，继承 BaseChatMessageHistory
   - 以 session_id 为文件名，本地 JSON 持久化
   - add_messages / messages / clear 三个核心方法

6. app_qa.py —— 主程序（Web 聊天界面）：
   - Streamlit 构建聊天界面
   - 使用 session_state 缓存 RAG 实例与聊天记录
   - 流式输出 AI 回答（write_stream）

7. app_file_uploader.py —— 知识库更新界面：
   - 单文件 txt 上传组件
   - 调用 KnowledgeBaseService.upload_by_str 入库

五、整体架构与工作流程
--------------------------------------------------------------------------------
【离线阶段：知识入库】
  1. 读取 data/ 目录下的 txt 文档
  2. 计算全文 MD5，判断是否已入库（去重）
  3. 超长文本用 RecursiveCharacterTextSplitter 分片（chunk_size=1000，overlap=100）
  4. 用 DashScope text-embedding-v4 将分片向量化
  5. 写入 Chroma 向量库，附元数据（来源、时间、操作人）
  6. 保存 MD5 记录，避免重复导入

【在线阶段：问答检索】
  1. 用户通过 Streamlit 界面输入问题
  2. 检索器在 Chroma 中检索 Top-K 最相似文档片段
  3. 拼接参考资料 + 历史对话 + 用户问题，组装 Prompt
  4. 通义千问（qwen3-max）生成回答
  5. 流式返回并展示，同时持久化本次对话到本地 JSON

【RAG 链数据流】：
  {"input": RunnablePassthrough(),
   "context": 提取query → 向量检索 → 格式化文档}
  → 数据结构适配 → Prompt 模板 → 调试打印 → 大模型 → 字符串解析

六、知识库内容（data/ 目录）
--------------------------------------------------------------------------------
1. 01_招生政策.txt        ：2025 年招生章程（学费、奖助学金、录取规则等）
2. 02_院校专业介绍.txt     ：计算机应用技术等专业介绍
3. 03_历年录取分数线.txt   ：山西省历年录取分数线、位次、热门专业平均分
4. 05_校园规章制度.txt     ：学生考勤管理规定等
5. 06_校园服务指南.txt     ：后勤服务大厅、校医院等服务信息
6. 尺码推荐.txt           ：身高体重对应服装尺码
7. 竞赛获奖.txt           ：昇腾 AI 创新大赛等竞赛获奖情况

（注：该知识库模拟的是一所"西安信息职业大学"的招生问答场景，
  还额外混入了服装尺码推荐等非招生类资料用于测试。）

七、关键技术要点
--------------------------------------------------------------------------------
1. 缓解幻觉：通过 RAG 让模型"以参考资料为主"回答，回答有据可查
2. MD5 去重：计算全文 MD5，重复文档跳过入库
3. 文本分片：递归字符分割 + 重叠，保证长文本上下文连贯
4. 多轮记忆：RunnableWithMessageHistory + 自定义 JSON 文件存储
5. 数据适配：RunnableLambda 做数据结构转换，衔接检索与 Prompt 模板
6. 流式输出：Streamlit write_stream 实现打字机式回答

八、运行方式
--------------------------------------------------------------------------------
1. 知识库入库：python knowledge_base.py（批量导入 data/ 目录文档）
2. 启动问答界面：streamlit run app_qa.py
3. 知识库更新界面：streamlit run app_file_uploader.py
4. 直接测试 RAG：python rag.py

九、总结
--------------------------------------------------------------------------------
这是一个完整、可运行的 RAG 项目教学案例，覆盖了 RAG 的核心链路：
"文档入库 → 向量化 → 检索 → 增强 Prompt → 生成回答 → 多轮记忆"。
代码结构清晰、注释详尽，适合作为学习 LangChain + Chroma + 通义千问
搭建 RAG 应用的入门项目。

（说明：代码中硬编码了 DashScope API Key，实际使用时应替换为自己的密钥，
  并注意密钥的保密管理，避免泄露。）
